# FadDompet v1.4.0

Rilis ini berfokus pada pembaruan identitas visual aplikasi: logo dan icon FadDompet yang baru.

## Pembaruan

- Mengganti logo aplikasi dengan desain FadDompet terbaru.
- Memperbarui icon launcher di home screen dan daftar aplikasi Android, termasuk adaptive icon.
- Memperbarui tampilan brand icon di dalam aplikasi agar konsisten dengan logo baru.
- Memperbarui tanda tangan aplikasi (app signing) ke kunci rilis baru.
- Memperbarui versi aplikasi ke 1.4.0.

## Penting untuk Pengguna v1.3.0 atau Lebih Lama

Versi ini memakai kunci tanda tangan baru, sehingga tidak bisa dipasang menimpa versi lama secara langsung. Agar data tetap aman, lakukan 4 langkah berikut:

1. Buka FadDompet versi lama, masuk ke menu **Pengaturan**, pilih **Data & Cadangan**, lalu ketuk **Cadangkan Data**. Simpan file cadangan (JSON) ke lokasi yang mudah diingat, misalnya folder Download.
2. Uninstall (hapus) aplikasi FadDompet yang lama.
3. Pasang APK v1.4.0 dari halaman rilis ini.
4. Buka FadDompet versi baru, masuk ke **Pengaturan**, pilih **Data & Cadangan**, lalu ketuk **Pulihkan dari Cadangan** dan pilih file cadangan yang tadi disimpan.

Data lama akan kembali utuh. Jika baru pertama kali memakai FadDompet, cukup langsung pasang APK-nya.

## Download

Untuk sebagian besar HP Android modern, gunakan:

`FadDompet-v1.4.0-arm64.apk`

## Catatan

FadDompet berjalan offline, tanpa akun, tanpa cloud sync, tanpa iklan, dan tanpa tracking. Data disimpan lokal di perangkat.

File cadangan berisi data keuangan, jadi simpan di tempat yang aman.

Jika memasang APK dari luar Play Store, Android atau Play Protect mungkin tetap menampilkan peringatan.
